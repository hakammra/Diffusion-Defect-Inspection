# Curated experiment evidence

This directory contains small, reviewable outputs intended for version control. Raw datasets, checkpoints, source caches, ZIP archives and full residual arrays remain excluded.

- `integration/`: author-path execution report and preview.
- `synthetic_baseline/`: generated pipeline-check metrics and preview.
- `mvtec_leather/`: locked reduced-evaluation report, per-image metrics, training curve and preview.
- `fabric_stain/`: locked image-level evaluation report, per-image scores, ROC curve, training curve and preview.
- `printed_labels/`: normal-only training, calibration and model-selection evidence; `final/` contains the first locked real-test report, per-image and per-physical-label results, and previews.

Qualitative images are supporting evidence only. Use the aggregate reports when describing performance.
